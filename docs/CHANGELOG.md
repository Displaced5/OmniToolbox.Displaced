# 更新记录

## 自动装配面部、时尚配饰 1.2.3

- 修复启用时同步创建服务导致的框架线程等待环，改由 `FeatureLifetime.TrackStartup` 跟踪异步初始化。
- 异步读取配饰记忆，返回框架线程后应用记忆并建立游戏数据目录与事件订阅。
- 事件解绑分别交由 `OnStopping` 管理，停止后拒绝迟到回调，初始化失败、取消和最终销毁均由宿主统一收尾。
- 保留模块内部名、命令、记忆路径和 B 方案，不修改独立 Dalamud 版。
- 增加实际模块启用／停用回归检查：79 项逻辑检查、39 项集成检查通过，尚未游戏内验证。
